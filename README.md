<h1>Rocket Engine Simulator</h1><p>Rocket Engine Simulator is an educational, strategic simulation game where players design, build, and test liquid rocket engines using real-world physics. You run a scrappy startup rocket company, balancing cost, mass, complexity, and reliability across a campaign of increasingly challenging levels while learning authentic rocket engineering concepts through hands-on experimentation.</p><h2>Core Experience</h2><ul><li><p><strong>Design–Build–Test loop</strong>: select a level goal, assemble an engine from components, run a test fire, analyze performance, and iterate.</p></li><li><p><strong>Meaningful trade-offs</strong>: budget constraints (money, weight, complexity, propellant) force smart engineering decisions.</p></li><li><p><strong>Progressive mastery</strong>: unlock advanced components, materials, and propellants as you move from a garage workshop to a world-class test facility.</p></li><li><p><strong>Accessible realism</strong>: physics-driven thrust, Isp, chamber pressure, and thermal loads are simplified where needed while still teaching real principles.</p></li><li><p><strong>Narrative flavor</strong>: witty startup banter and real-world engineering challenges frame each milestone.</p></li></ul><h2>Repository Purpose</h2><p>This repository will ultimately be the home for the game’s source code, tools, and supporting assets as development progresses.</p><p>Adding this not there to see if the save or edit feature works.</p>
